# 直式乘法練習

[野生的葦達鴨](https://github.com/weiduck) 做的平板練習。給國小資源班學生（書寫困難）用**點選**學直式乘法。開啟後直接進入單題練習。

線上版：[weiduck.github.io/tablet-mult](https://weiduck.github.io/tablet-mult/)

十二個**題型**依循 **康軒數學 4 上 第 02 單元「整數的乘法」資料冊學習目標**（課綱 N-4-2：較大位數之乘除計算；以**位值**說明直式合理性）。進入題型或重試時，會依該題型約束**隨機出題**；**有／無乘進位是題型內的難度變化**（不是獨立按鈕）。

## 怎麼打開

不需要安裝或建置。

1. **線上**：用瀏覽器開 [weiduck.github.io/tablet-mult](https://weiduck.github.io/tablet-mult/)
2. **直接開檔**：用瀏覽器開啟本資料夾的 `index.html`
3. **本機靜態伺服器**（若瀏覽器擋 `file://` 字型／manifest）：在本資料夾執行

```bash
python3 -m http.server 8765
```

然後開 `http://localhost:8765/`。

### 加到 iPad 主畫面（像 App 一樣全螢幕）

1. 用 **Safari** 打開 [線上版](https://weiduck.github.io/tablet-mult/)（不要用 `file://`）
2. 點底部分享按鈕 → **加入主畫面**
3. 名稱會是「直式乘法」；加入後從主畫面圖示開啟
4. 請把 iPad **轉成橫向**；直向時會出現「請把 iPad 轉成橫向」提示
5. 以 standalone／全螢幕方式執行，頁面不會亂橡皮筋滾動；僅卡片／步驟區在內容過長時可內部捲動

適合橫向全螢幕；選項按鈕點擊目標約 ≥ 48–56px。

## 康軒資料冊 12 題型（學習目標）

| 題型 | 類型 | 隨機約束（例） | 直式做法 |
|------|------|----------------|----------|
| 1 | 整千×一位 | 被乘數為 d000；乘數 2–9（如 3000×2） | 教冊捷徑：先算 3×2＝6（6 個千），再補 3 個 0 → 6000；4 步（7000×8＝56000 為 5 步） |
| 2 | 四位×一位 | 四位、中間百／十皆非 0；乘數 2–9（如 1426×3） | 一排 |
| 3 | 四位×一位、被乘數中間有0 | 百位或十位為 0、非整千；乘數 2–9（如 2035×4） | 一排 |
| 4 | 一位×整十 | 被乘數 2–9；乘數為整十（如 8×20） | 教冊捷徑：先算 8×2＝16（16 個十），再補 1 個 0 → 160；3 步 |
| 5 | 一位×二位 | 被乘數 2–9；乘數二位且個位≠0（如 6×28） | 兩排＋相加（48＋120）；一位數保持在上，不用交換律改寫 |
| 6 | 整十×整十 | 兩數皆為整十（如 30×50） | 教冊捷徑：先算 3×5＝15（15 個百），再補 2 個 0 → 1500；4 步 |
| 7 | 二位×二位、積為三位數 | 兩數二位、個位≠0；積 100–999（如 12×13） | 兩排＋相加 |
| 8 | 二位×二位、積為四位數 | 兩數二位、個位≠0；積 1000–9999（如 48×27） | 兩排＋相加 |
| 9 | 三位×二位 | 被乘數三位且十位≠0；乘數二位個位≠0（如 386×59） | 兩排＋相加 |
| 10 | 三位×二位、被乘數中間有0 | 被乘數十位為 0、個位≠0（不出整百如 500）；乘數二位個位≠0（如 203×45） | 兩排＋相加 |
| 11 | 四位×二位 | 被乘數四位且百／十皆非 0；乘數二位個位≠0（如 2345×67） | 兩排＋相加 |
| 12 | 四位×二位、被乘數中間有0 | 被乘數百位或十位為 0、非整千；乘數二位個位≠0（如 1005×23） | 兩排＋相加 |

**一排**：乘數只有一位（題型 2、3）或整千／整十捷徑（題型 1、4、6）時，乘出來直接寫在「答案」列，不顯示第二排、加法進位，也沒有相加步驟。被乘數只有最高位非 0（題型 1、4、5、6）時不會有乘進位，乘進位列也不畫。

每個題型的約束在 `mult-core.js` 寫成明確的判斷式 `MultCore.checkType(i, a, b)`（`i` 從 0 起算：題型 N ＝ `i = N − 1`），產生器出的題一定通過，並由 `npm test` 檢查。

跳轉鈕分兩列顯示（上列題型 1–6、下列題型 7–12，「隨機」在第二列末端），標示「題型 1」…「題型 12」並附類型說明；「隨機」可抽一題型並重新出題。「再練一次」與 ↻ 皆**留在同一題型**重抽數字。

**進位**：在適用題型內，產生器會隨機偏好有／無乘進位（找不到則放寬），不再拆成「有進位／無進位」兩個題型。「乘進位」指寫進①②進位格的那種。題型 1（整千×一位）、4（一位×整十）、5（一位×二位）、6（整十×整十）的被乘數只有最高位非 0，最高位乘出的十位直接寫進該排（如 3000×4＝12000 只是積多一位），板上不會有進位格，所以這四個題型**不適用**有／無乘進位，直接隨機出題。

**直式板寬度**：積為四位數以內用四欄（千百十個）；五／六位數積自動加寬（萬／十萬），以容納三／四位×二位等題型。

教學重點（依康軒 4 上第 2 單元教冊）：

- **學生自己算**：題目只給算式不給積，例如「4 × 7 + 進位 5 = ?，十位寫幾？」；完整的積只在第 2 層提示或答對後才出現。
- **位值對齊**：第二排其實是 ×n0，算出來是「幾個十」，個位放 0（課本說也可以省略不寫，這裡點 0 放好位置）。整千、整十題用教冊捷徑：先乘不是 0 的數字（算出幾個千／十／百），再補上 0 的數量（3000×2 補 3 個、8×20 補 1 個、30×50 補 2 個），不做 0×b 的步驟。
- **一位×二位不交換**：6×28 保持一位數在上（教冊建議不要寫成二位數×一位數）。
- **進位**：乘法進位與加法進位都由學生點選，寫在上方小格（「進位 n 寫在上方小格」）；每張卡只在第一個進位步驟提醒一次，之後只在提示裡。不提「記在紙上」（學生有書寫困難，進位格就在板上）。
- **常見錯誤當誘答**（教冊：忘了進位、乘十位時放錯位值）：四個選項是正解＋忘了加進位、寫成十位數、進位加兩次、隔壁位、用加的（或用乘的）等；不夠才補 ±1、9−x。選到這類選項會說明錯在哪，例如「好像忘了加進位 3。」

## 體驗概要

| 區塊 | 行為 |
|------|------|
| 開啟 | 直接進入「單題練習」，無示範分頁 |
| 題型 | 十二題型跳轉＋「隨機」；每次進入／重試隨機出題 |
| 直式板 | 只畫這題用得到的列：進位／被乘數／乘數／（第一排／第二排／加法進位）／答案；底列定位；欄數隨積加寬 |
| 格狀態 | 空＝虛線；目前＝黃底粗藍框；已填＝淡綠；紅圈＝當下相乘（或相加）的數；虛線紅圈＝要加上的進位 |
| 右欄 | 階段（標位值）＋題目（不給積）、2×2 四選一、三層提示、對／錯回饋 |
| 提示 | 「給我一個提示」逐層打開（按鈕標「提示 1/3」…）：① 概念（看哪兩個數、哪一位、記得加進位）② 算式（如 4 × 7 = 28，28 + 5 = 33）③ 這一格寫幾；第 3 層後再按收起 |
| 點錯 | 錯的選項變紅、不能再點，並顯示錯因；同一步錯 2 次自動打開第 2 層提示（已打開就往下一層），錯 3 次打開第 3 層並用虛線框出正確選項 |
| 答對 | 顯示完整算式（如「4 × 7 + 進位 5 = 33，十位寫 3。」），數字填進格子 |
| 補 0 | 第二排**整排乘完後**個位由學生點選 0；整千／整十捷徑題由學生一格一格點選補上的 0 |
| 完成 | 兩排題顯示部分積相加；一排題顯示答案；捷徑題顯示「3 × 5 = 15，再補上 2 個 0」 |

二位×二位主例 `48 × 27`（積 1296）共 **13 步**：個位排（含進位）→ 十位排（含進位）→ 補 0（點選）→ 從右往左相加（加法進位也點選）。`3000 × 2` 共 4 步、`8 × 20` 共 3 步、`30 × 50` 共 4 步。

## 檔案

- `index.html` — 結構、繁中文案、PWA／主畫面 meta
- `styles.css` — 粗獷／貼紙感樣式；橫向全螢幕、鎖捲動、safe-area
- `mult-core.js` — 純邏輯（不碰 DOM，UMD）：12 題型約束 `checkType`／產生器 `generate`（可注入亂數 `makeRng(seed)`）、一步一問步驟引擎 `buildSteps`（題目、三層提示 `hints`、答對說明 `reveal`、要顯示的列 `visibleRows`）、完成板、常見錯誤選項 `buildChoices`；瀏覽器為 `window.MultCore`（舊名 `window.MuseMult` 指向同一物件），Node 可 `require`
- `app.js` — 畫面：直式板繪製、題型跳轉、作答流程、方向提示／觸控鎖（使用 `MultCore`；須在 `mult-core.js` 之後載入）
- `test/generator.test.js` — 產生器／步驟引擎檢查（Node 內建 `node:assert`，無相依套件）
- `package.json` — 只有 `npm test` 指令，沒有相依套件
- `manifest.webmanifest` — 主畫面名稱「直式乘法」、landscape、standalone
- `apple-touch-icon.png` / `icon-192.png` / `icon-512.png` — 圖示
- `README.md` — 本說明

## 明確不做

- 手寫辨識、拖曳
- 登入／後端／雲端進度
- 建置工具（Webpack、Vite 等）

## 快速檢查

```bash
node --check mult-core.js && node --check app.js
npm test   # 或 node test/generator.test.js；不需 npm install
```

`npm test` 會：每個題型用固定種子抽 1000 題檢查 `checkType`、欄寬、有／無乘進位比例；2000 組跨題型隨機題＋指定題（48×27、2035×4、1005×23、3000×2、8×20、30×50、6×28、12×13、203×45、2345×67）檢查答案列＝a×b、每步答案是 0–9 一位數、每格最多填一次、所有虛線格最後都會填上且都在顯示的列裡、每個進位格都是學生點選的一步。每一步也檢查：題目不先說出積／和、第 1 層提示沒有任何數字、第 2 層不說「寫幾」、第 3 層才說；四個選項是不同的 0–9 一位數且含正解、同種子結果相同。另外有常見錯誤誘答（忘了進位、寫成十位、進位加兩次）、整千／整十捷徑（3000×2、7000×8、8×20、30×50 及題型 1／4／6 全部組合，不出現 0× 步驟）、乘數一位只有一排等專門測試。失敗時結束碼非 0。

在瀏覽器 Console 也可（`MuseMult` 與 `MultCore` 是同一物件）：

```js
MultCore.buildSteps(48,27).steps.length  // → 13
MultCore.buildSteps(48,27).steps[2].hints  // → 三層提示（概念／算式／寫幾）
MultCore.buildChoices(MultCore.buildSteps(48,27).steps[2], MultCore.makeRng(1))  // → { values, why }
MultCore.buildSteps(30,50).steps.map(s => s.answer)  // → [5,1,0,0]
MultCore.buildCompletedBoard(48,27).board.answer  // → [1,2,9,6]
MultCore.TYPES.length  // → 12
MultCore.TYPES.map((t,i) => (i+1)+": "+t.stage+" → "+JSON.stringify(MultCore.generate(i)))
MultCore.generate(9, { rng: MultCore.makeRng(42), carry: true })  // 可重現；carry 指定偏好
MultCore.checkType(9, 500, 45)  // → false（題型 10 不出整百）
MultCore.colsFor(2345,67)  // → 6（積 157115）
```
