# 直式乘法練習

給國小資源班學生（書寫困難）在**平板上用點選**學直式乘法的靜態網頁。開啟後直接進入單題練習。

八個**題型**依循 **康軒數學 4 上 第 02 單元「整數的乘法」**（課綱 N-4-2：較大位數之乘除計算；以**位值**說明直式合理性）。進入題型或重試時，會依該題型約束**隨機出題**。

## 怎麼打開

不需要安裝或建置。任選一種：

1. **直接開檔**：用瀏覽器開啟本資料夾的 `index.html`
2. **本機靜態伺服器**（若瀏覽器擋 `file://` 字型／manifest）：

```bash
cd /Users/jerry/Projects/tablet-mult
# 或在本機對應路徑
python3 -m http.server 8765
```

然後開 `http://localhost:8765/`。

### 加到 iPad 主畫面（像 App 一樣全螢幕）

1. 用 **Safari** 打開本站（建議用本機伺服器或可連線的 URL，不要用 `file://`）
2. 點底部分享按鈕 → **加入主畫面**
3. 名稱會是「直式乘法」；加入後從主畫面圖示開啟
4. 請把 iPad **轉成橫向**；直向時會出現「請把 iPad 轉成橫向」提示
5. 以 standalone／全螢幕方式執行，頁面不會亂橡皮筋滾動；僅卡片／步驟區在內容過長時可內部捲動

適合橫向全螢幕；選項按鈕點擊目標約 ≥ 48–56px。

## 康軒 N-4-2 進度（題型）

| 題型 | 類型 | 隨機約束（例） |
|------|------|----------------|
| 1 | 四位數×一位數（整千） | 被乘數為 d000；積 ≤ 9999（如 3000×2） |
| 2 | 四位數×一位數 | 四位皆非 0；積 ≤ 9999（如 1426×3） |
| 3 | 四位數×一位數（中間有 0） | 百位或十位為 0、非整千；積 ≤ 9999（如 2035×4） |
| 4 | 一位數×整十 | 被乘數 2–9；乘數為整十（如 8×20） |
| 5 | 一位數×二位數 | 被乘數 2–9；乘數二位且個位≠0（如 6×28） |
| 6 | 整十×整十 | 兩數皆為整十（如 30×50） |
| 7 | 二位數×二位數（無進位） | 兩數二位、個位≠0；各位相乘皆 < 10（如 24×12） |
| 8 | 二位數×二位數（有進位） | 兩數二位、個位≠0；至少一處乘進位（如 48×27） |

跳轉鈕標示「題型 1」…「題型 8」，旁有「隨機」可抽一題型並重新出題。教學重點：位值對齊、第二排其實是 ×n0（個位補 0）、進位可記心裡／手指／紙上但勿擋相加。

## 體驗概要

| 區塊 | 行為 |
|------|------|
| 開啟 | 直接進入「單題練習」，無示範分頁 |
| 題型 | 八題型跳轉＋「隨機」；每次進入／重試隨機出題 |
| 直式板 | 進位／被乘數／乘數／第一排／第二排／加法進位／答案；底列定位（千百十個） |
| 格狀態 | 空＝虛線；目前＝黃底粗藍框；已填＝淡綠；紅圈＝當下相乘兩數 |
| 右欄 | 階段（標位值）＋大題、2×2 四選一、可展開提示、對／錯回饋 |
| 補 0 | 第二排**整排乘完後**個位由學生點選 0（一步，與其他數字相同） |
| 完成 | 顯示部分積相加與完整算式 |

二位×二位主例 `48 × 27`（積 1296）約 **12 步**：個位排 → 進位 → 十位排 → 補 0（點選）→ 從右往左相加。

兩位孩子共用同一套題型序（8 題型，數字隨機）：位值提示可點「給我一個提示」展開；格子大小適中。
